# Data availability

This GitHub repository contains the custom computational code, GROMACS simulation parameter files, run metadata, and compact derived summary tables used in the study.

## Data included in the repository

The repository includes:

- custom machine-learning and sequence-analysis scripts;
- sequence-generation and candidate-rescoring scripts;
- independent MD replicate metadata;
- GROMACS NVT, NPT, and 50-ns production MD parameter files;
- compact derived result summaries.

## Large data excluded from Git

Large molecular-dynamics trajectories and intermediate simulation files are not stored directly in Git because individual files can be several gigabytes in size.

These excluded files include large MD trajectories, binary simulation intermediates, and model checkpoints where applicable.

## Raw computational data

Raw Boltz-2 output tables and other large intermediate computational datasets are not stored in the source-code repository.

The custom code in this repository documents how these inputs were processed and analyzed.

## Final sharing location

The permanent sharing location for large raw and intermediate computational data has not yet been finalized.

Therefore, this repository does not currently claim that the excluded large files are permanently publicly available.

The final manuscript Data availability statement should be updated once a permanent data depository or other sharing mechanism has been defined by the authors.
